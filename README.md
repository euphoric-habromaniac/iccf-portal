# ICCF Portal

A competency certification portal for Manav Rachna University. Students take assessments and earn certifications. Staff manage the question bank and read results by department.

The portal is in development. This repository is a public summary only. The source code, data and design files are private, and this page doesn't say how the system works inside.

## What it does

- **Assessments for soft skills.** A bank of 15 human-centric skills (communication, empathy, ethics, resilience and so on), scored alongside regular subject competencies.
- **Five question types.** Likert, MCQ, scenario MCQ, ranking, and written answers graded against a rubric with AI.
- **Scorecards.** Each student sees a score and level for every skill, a radar chart, and how they've grown across attempts.
- **Certificates and reports.** Certificates, student transcripts, and assessment and department reports can be exported as PDFs.
- **Four roles.** Students, department heads, the core team and system admins each have their own dashboard.
- **Question moderation.** New questions are reviewed and approved before students ever see them.
- **Exam-day safeguards.** The timer and the answers survive a reload, and tab switches are monitored.
- **Bulk onboarding.** Staff can add whole classes of students and teachers from one spreadsheet.

## Built with

React 19, TypeScript, Vite, Tailwind CSS, Firebase Authentication, Cloud Firestore, Gemini, Recharts.
